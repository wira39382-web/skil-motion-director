# Runtime tools

## Scope and installation
The skill instructions and HTML viewing do not require Node. The optional capture tools use Node ES modules and Playwright. package.json records the development version; no lockfile is claimed until generated by an actual dependency installation. Run npm install and npx playwright install chromium only when needed and permitted by the environment; prefer already available browser tools. No TTS, MCP service, API key, or paid account is bundled.

Commands from the skill/repository root (quote paths with spaces):

```sh
npm test
node scripts/doctor.mjs
node scripts/doctor.mjs --launch
node scripts/snap.mjs assets/starter-offline.html artifacts/review-v1 1 4 8 11.9
node scripts/export-frames.mjs assets/starter-offline.html artifacts/frames-v1 30
node scripts/encode.mjs artifacts/frames-v1 artifacts/demo-v1.mp4
node scripts/encode.mjs artifacts/frames-v2 artifacts/narrated-v2.mp4 narration.wav
```

The output folder for screenshots/frames must be empty. A partial failure leaves its files for diagnosis; use a new versioned folder for retry. MP4 output must not exist; FFmpeg -n prevents overwrite. encode.mjs checks input frame files and video/audio metadata. It refuses audio longer than the visual duration (small codec tolerance); shorter audio is padded with silence. Listen to the result: presence of AAC does not prove sync, correct words, loudness, or intelligibility.

The capture contract is window.OPENER = {W,H,DURATION,ready,seek(t),play(),pause()}; seekFrame(t) is optional for footage. Capture uses the same time authority as preview, never wall-clock animation. For a GSAP master timeline pause before capture and suppress autonomous playback; ensure fonts/images/video are decoded before ready. CSS loops independent of the master timeline must be converted or controlled.

Remote dependencies are recorded in capture-report.json. No remote requests is evidence of portability only for the tested path and assets, not every possible project. Screenshot capture never records HTML audio.

Upstream Python/AE helper files remain optional recipes and are not implied to have been tested here. Avoid AE/Higgsfield unless explicitly requested and connected.
